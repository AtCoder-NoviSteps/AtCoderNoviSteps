3-1 で決めること:

- **`available` が 1 でない問題の扱い**。3643 は 2026-10-10 に AOJ に追加されたばかりで、`available` が 4、提出が 0。公開前の状態なら、AOJ のコンテスト一覧に入った後で管理画面の取り込みで入れられるかもしれない。手で INSERT するか、一覧に入るのを待つかを決める。先に `available` の値の意味と、判明分（1123 を含む）の値を確かめる

3-2 で決めたこと（2026-10-28）。根拠、採らなかった案の詳細、影響範囲は [investigation.md の 7 章](./investigation.md#7-pr3-のダミーの設計と影響範囲)。

- **`task_id`**: `NoJudge-{contest_id}_{記号の小文字}`（例: `NoJudge-JAGWinter2006-day2_a`）。`task_table_index` は大文字（`A`）のまま。不採用: 数字（100000 番台、50xx 番台）、`Missing-` などの接頭辞
- **リンク先**: jag-icpc.org の大会区分のページ（例: `2008/Practice/模擬地区予選`、計 5 ページ）。自分で採点するのに要る問題文・ジャッジデータ・講評のどれにも下りられる。不採用: PDF への直リンク、`問題文とデータセット` のページ
- **リンク先の持ち方**: `getTaskUrl()`（`src/lib/utils/task.ts`）の URL ジェネレータに `NoJudgeGenerator` を足し、`AojGenerator` より前に置く。`UrlGenerator.canHandle` に `taskId` を足す（既存の 2 つの実装は書き換え不要）。判定は出典のラベルと共通の `isNoJudgeTask()`、URL は `task_id` をキーにした map から引く。map は `{ url, taskIds }` をページごとに並べて組み立てる。URL はブラウザで開けたものをパーセントエンコードのまま貼る。テストで、URL をそのまま返すこと、ジェネレータの並び順、seed の `NoJudge-` が全件 map にあることを固定する。不採用: `getTaskUrl()` の先頭で map を引く、Task に `url` 列を足す
- **出典のラベル**: ダミーは `（AOJ）` ではなく `（No Judge）` にする（例: `JAG 冬合宿 2006 Day2 - A（No Judge）`）。汎用関数 `addContestNameToTaskIndex()`（`src/lib/contests/utils/task_index_label.ts`）に `taskId` を省略できない引数として足し、呼び出し元 6 ファイル（7 か所）で渡す
- **見た目**: アイコンもツールチップも入れない。採点が無いことは出典のラベルの文字で伝える
- **投票・タグ・問題集・コンテスト別の表**: すべてに出す。Task のレコードを足せば動き、コードの変更は `getTaskUrl()` と `addContestNameToTaskIndex()` の 2 つ
- **AOJ に後から追加されたら**: `task_id` を AOJ の ID に UPDATE し（参照する外部キーはすべて `ON UPDATE CASCADE`）、map のエントリを消す。出典のラベルは `task_id` から決まるので、自動で `（AOJ）` に戻る
