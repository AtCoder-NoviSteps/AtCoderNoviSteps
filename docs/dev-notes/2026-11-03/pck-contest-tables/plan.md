# PCKの問題番号とコンテスト別一覧表

PCKの問題番号をAOJ問題IDからコンテストごとの連番に変え、予選・本選の年度別一覧表を追加した。全581問をシードとマイグレーションでそろえる。

## 決定事項

- AOJ未掲載の問題の元の位置は復元しない（例：本選2011年は掲載3問を1〜3とする）。
- reset・再シードを不要にするため、マイグレーションのUPSERTで反映する。staging・本番にも未登録問題がPENDINGで追加されることは、ユーザーが了承した。
- 新規問題のグレードはAOJの統計値から推定しない。

## データ出典

- 予選2026年の12問は、ユーザーが貼り付けた公式APIレスポンスから追加した（実装環境からAOJ APIに接続できなかった）。本選2026年はレスポンスになく、追加していない。
- 依頼の例では予選2026年の1番は `4086` だったが、公式一覧の先頭の `4084` に従った。

## 採用しなかった案

- 表示時だけ連番に置き換える：DB・ラベル・取り込みで番号が食い違う。
- ICPC・JAG型の `ROW_NUMBER()` によるUPDATE：未登録問題を追加できないため、全581問をSQLに埋め込んだ。
- 再シード：登録済みの `task_id` はスキップされ、番号が更新されない。
- PCK用のContestType・コンポーネントの新設：既存の仕組みで足りる。

## 検証とレビュー

- マイグレーションとシードの581問は一致し、`task_id` の重複はない。
- ローカルのPostgreSQL（適用前はPCK 96問、全件が旧形式）で適用し、更新96・追加485、旧形式0件、再実行で変化なしを確認した。E2E・単体テスト・lint・checkも成功した。
- Codexのクロスレビューの指摘は0件。別コンテストに同じ `task_id` がある行は黙ってスキップされるが、現状起こり得ないため対応しない。
- 未確認：staging・本番の既存データへの適用結果。
