# AWC 0201 以降のテーブル

Issue: #4325（参考: PR #4006、AWC 0200 対応の #4320）

## 決定事項

awc0201 以降を `AWCRangeProvider`（`AWC::0201Onwards`、201〜9999）で表示し、`AWC0001Onwards` グループの先頭（AWC 0200 の表の上）に登録した。ボタンは既存のまま。

| 表示順 | provider key       | 範囲・対象                                         |
| ------ | ------------------ | -------------------------------------------------- |
| 1      | `AWC::0201Onwards` | awc0201〜awc9999（A〜E）                           |
| 2      | `AWC::0200`        | awc0200（15 問）                                   |
| 3 以降 | 既存のまま         | 0151〜0199 / 0150 / 0101〜0149 / 0100 / 0001〜0099 |

- 命名・上限・title は旧 `0151Onwards`（`maxRound: 9999`、`'AtCoder Weekday Contest 0151 〜'`）に揃えた。新しい class・関数・型は追加していない。
- 却下: `0201To0249` のように上限を閉じる案。awc0250 が特殊回かは未確定で、閉じると 0250 以降がどの表にも出なくなる。
- 却下: 新しいボタン（グループ）を作る案。ユーザーの指示で既存ボタンを維持した。

## コードと履歴に残らない事実

- awc0200 の seed の実問題名は、ユーザーが貼った行（15 問、A〜O）から取った。本番 DB には投入済みなので、本番側の作業はない。
- awc0201 の seed と fixture はダミー（`Dummy Problem A`〜`E`）。5 問は通常回に合わせた仮定。回内の並びは既存の AWC ブロックに合わせて A→E にした（add-tasks チェックリストの F→A とは異なる）。
- 変異の検出: `minRound: 201` → `200` は `shows awc0200 only in AWC::0200` が、`maxRound: 9999` → `201` は `shows awc0202 only in AWC::0201Onwards` が検出した（それぞれ 46 件中 1 件が失敗）。
- `oxfmt --check`（変更ファイル）/ `pnpm lint` / `pnpm check` / `pnpm test:unit`（3109 件）/ `git diff --check` はすべて通過した。`pnpm format` はリポジトリ全体を書き換えるため使っていない。
- 未確認: `pnpm db:seed` 後の dev サーバーでの目視（0201 の表が 0200 の上に出ること）。ローカル DB に書き込むため実施していない。

## 残タスク

- awc0201 の開催後、seed のダミー名を実問題名に差し替える。問題数が 5 問でなければ fixture とテストも直す。
- awc0250 が特殊回になったら、`0201Onwards` を `0201To0249` に狭め、`AWCSpecialContestProvider` を追加する。
